### How to use / Guide
***In order to use shader files, please compile shader files to .spv using glslc (From GLSL to SPIR-V)***\
***SPIR-V shader files WILL NOT be included into this repository unless if needed***
- Clone the repository using `git clone https://github.com/MuangthaiDotEXE/Vulkan-Graphics-Engine.git --recursive`
- Create "Build" directory and run `cmake ..` and `cmake --build .` inside the directory (Make sure you have all the required libraries)
- Once completed, you should be (mostly) ready to go
